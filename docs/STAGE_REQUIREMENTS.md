# УП.08 Stage Requirements

## Общие требования

Проект готов, если:

✅ используется frontend-фреймворк
✅ есть backend
✅ есть база данных
✅ проект опубликован
✅ код находится на GitHub
✅ заполнен README

# Этап 1. Техническое задание

Нужно создать:
- описание проекта;
- пользователей;
- сценарии;
- анализ конкурентов;
- sitemap;
- ER-диаграмму;
- выбор стека.

Готово когда:
✅ есть ТЗ
✅ есть структура сайта
✅ есть схема БД

# Этап 2. Дизайн

Создать:
- мудборд;
- UI-kit;
- wireframe;
- макеты страниц.

Готово когда:
✅ есть desktop дизайн
✅ есть mobile дизайн
✅ есть прототип

# Этап 3. Frontend

Создать:
- приложение через Vite;
- компоненты;
- адаптивную вёрстку;
- первый деплой.

Готово когда:
✅ главная страница работает
✅ сайт доступен по ссылке

# Этап 4. Навигация

Создать:
- маршруты;
- меню;
- страницы;
- якорные ссылки.

Готово когда:
✅ все страницы открываются
✅ работает мобильное меню

# Этап 5. База данных и API

Создать:
- БД;
- REST API;
- вывод данных.

Готово когда:
✅ есть 3+ связанные таблицы
✅ API работает
✅ данные приходят из БД

# Этап 6. Формы

Создать:
- регистрацию;
- авторизацию;
- основные формы проекта.

Готово когда:
✅ данные сохраняются
✅ есть проверки
✅ реализована безопасность

# Этап 7. Анимации

Создать:
- слайдер;
- анимации;
- финальный деплой.

Готово когда:
✅ сайт стабильно работает
✅ README обновлён
✅ проект готов к защите

# Финальная проверка

✅ публичная ссылка работает
✅ репозиторий заполнен
✅ коммиты понятные
✅ можно показать архитектуру проекта
