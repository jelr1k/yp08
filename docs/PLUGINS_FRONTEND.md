# Frontend Development Plugins

## Назначение
Документ описывает инструменты для разработки интерфейса проекта УП.08.

Frontend отвечает за:
- страницы;
- компоненты;
- адаптивность;
- работу с API;
- анимации.

## GitHub
Использование:
- хранение проекта;
- история изменений;
- проверка структуры.

## Figma
Используется для:
- создания макетов;
- UI-kit;
- прототипов.

Требования:
- desktop макеты;
- mobile макеты;
- компоненты;
- стили.

## Frontend Framework
Использовать:
- React;
- Vue;
- Svelte;
- Angular.

## Проверка интерфейса
Проверять:
- соответствие макету;
- адаптивность;
- структуру компонентов;
- качество UI.

## Frontend готов когда

### Макет
✅ есть UI-kit
✅ есть desktop и mobile версии
✅ есть прототип

### Вёрстка
✅ проект создан через Vite
✅ компоненты разделены
✅ стили подключены
✅ адаптивность работает

### Навигация
✅ работают маршруты
✅ есть меню
✅ есть 404 страница

### Данные
✅ данные приходят с API
✅ есть загрузка и ошибки
✅ есть поиск и фильтры

### Анимации
✅ есть слайдер
✅ есть эффекты появления
✅ есть hover-анимации
