# Техническое задание
## Проект Н4: «Портфолио-платформа студентов-дизайнеров»

## 1. Общая информация

**Название проекта:** Portfolio Hub

**Тип проекта:** веб-приложение для создания и демонстрации цифровых портфолио.

**Тематика:** платформа для студентов и начинающих специалистов в сфере дизайна.

Цель проекта — создать единое пространство, где пользователи могут размещать свои работы, просматривать проекты других авторов и находить специалистов.

Проект включает frontend, backend, базу данных, GitHub и публичный деплой согласно требованиям УП.08.

---

# 2. Цель проекта

Создание современной веб-платформы для публикации творческих работ с возможностью управления проектами, взаимодействия пользователей и поиска работ по направлениям.

Основные направления работ:
- UI/UX дизайн;
- 3D-графика;
- иллюстрации;
- веб-дизайн.

---

# 3. Целевая аудитория и портреты пользователей

## Персона 1: Студент-дизайнер

**Возраст:** 16–25 лет.

**Роль:** автор работ.

**Цель:** создать портфолио и показать свои навыки.

**Потребности:**
- загрузка проектов;
- добавление описаний;
- публикация изображений;
- получение оценок от пользователей;
- поиск вдохновения.

**Сценарий использования:**
Пользователь регистрируется, создаёт профиль, загружает работу, выбирает направление (UI, 3D, иллюстрация), добавляет описание и публикует проект.

## Персона 2: Заказчик / работодатель

**Возраст:** 25+ лет.

**Роль:** пользователь, который ищет специалистов.

**Цель:** найти автора с подходящими навыками.

**Потребности:**
- просмотр каталога;
- поиск работ;
- фильтрация по направлениям;
- оценка уровня специалиста.

**Сценарий использования:**
Пользователь открывает каталог, выбирает нужное направление, просматривает проекты, открывает профиль автора и оценивает его работы.

---

# 4. Сценарии использования сайта

## Просмотр работ
1. Пользователь открывает главную страницу.
2. Переходит в каталог проектов.
3. Использует фильтр по направлениям.
4. Открывает страницу выбранной работы.

## Публикация работы
1. Автор проходит авторизацию.
2. Переходит в личный кабинет.
3. Создаёт новый проект.
4. Загружает изображение и описание.
5. Выбирает категорию.
6. Публикует работу.

## Взаимодействие с проектами
1. Пользователь открывает работу.
2. Ставит лайк.
3. Оставляет комментарий.
4. Может перейти в профиль автора.

# 6. CRUD-функциональность

CRUD — основные операции работы с данными.

## Projects (работы пользователей)

**Create (создание):**
- добавление новой работы;
- загрузка изображения;
- указание названия, описания и категории.

**Read (чтение):**
- просмотр каталога;
- просмотр страницы проекта;
- просмотр проектов автора.

**Update (изменение):**
- редактирование названия;
- изменение описания;
- изменение категории;
- замена изображения.

**Delete (удаление):**
- удаление собственной работы пользователем.

## Users (пользователи)

CRUD включает:
- создание аккаунта;
- просмотр профиля;
- изменение данных профиля;
- удаление аккаунта.
