# Техническое задание
## Проект Н4: «Портфолио-платформа студентов-дизайнеров»

## 1. Общая информация

**Название проекта:** Portfolio Hub

**Тип проекта:** веб-приложение для размещения и демонстрации творческих работ студентов.

**Тематика:** портфолио-платформа студентов-дизайнеров.

Проект предназначен для создания единого пространства, где студенты могут публиковать свои работы, получать обратную связь и находить интересные проекты других участников.

Проект соответствует требованиям учебной практики УП.08 «Разработка дизайна веб-приложений»: приложение должно использовать frontend-фреймворк, серверную часть, базу данных, GitHub и публичный деплой.

---

# 2. Цель проекта

Создать современную адаптивную веб-платформу для публикации дизайнерских проектов студентов с возможностью просмотра работ, фильтрации по направлениям, добавления оценок и управления личным профилем.

---

# 3. Целевая аудитория

## Персона 1: Студент-дизайнер

**Возраст:** 16–25 лет.

**Цель:** показать свои работы и собрать портфолио.

**Потребности:**
- загрузка проектов;
- описание работ;
- добавление изображений;
- получение лайков и отзывов;
- поиск вдохновения.

## Персона 2: Работодатель или заказчик

**Возраст:** 25+ лет.

**Цель:** найти начинающего специалиста.

**Потребности:**
- просмотр работ;
- фильтрация по направлениям;
- оценка уровня автора.

---

# 4. Основные сценарии использования

1. Пользователь открывает главную страницу.
2. Просматривает каталог проектов.
3. Использует фильтр по направлениям:
   - UI/UX дизайн;
   - 3D-графика;
   - иллюстрация;
   - веб-дизайн.
4. Открывает страницу проекта.
5. Авторизованный пользователь добавляет собственную работу.
6. Другие пользователи ставят лайки и оставляют отзывы.

# 11. Выбор технологий

## Frontend

React + Vite.

Причины выбора:
- популярный современный фреймворк;
- компонентный подход;
- большое количество инструментов.

## Стилизация

SCSS или Tailwind CSS.

## Backend

FastAPI или Node.js Express.

## База данных

PostgreSQL.

Причины:
- поддержка связей между таблицами;
- подходит для расширяемых проектов.
