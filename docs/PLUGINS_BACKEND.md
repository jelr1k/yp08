# Backend Development Plugins

## Назначение
Документ описывает инструменты для разработки серверной части проекта УП.08.

Backend отвечает за:
- API;
- базу данных;
- авторизацию;
- обработку форм;
- хранение данных.

## GitHub
Использование:
- хранение исходного кода;
- контроль изменений;
- Issues и задачи;
- проверка структуры проекта.

## Анализ кода
Используется для:
- поиска ошибок;
- проверки архитектуры;
- рефакторинга;
- улучшения читаемости.

## Database Tools
Используются для:
- проектирования БД;
- проверки связей таблиц;
- работы с миграциями.

Требования:
- минимум 3 связанные таблицы;
- seed-данные;
- миграции.

## API Testing
Инструменты:
- Postman;
- Thunder Client.

Проверяются:
- GET;
- POST;
- PUT/PATCH;
- DELETE.

## Backend готов когда

### Архитектура
✅ создан backend
✅ выбран фреймворк
✅ подключена БД
✅ есть инструкция запуска

### REST API
✅ CRUD работает
✅ данные приходят из БД
✅ ошибки обработаны

### Авторизация и формы
✅ регистрация работает
✅ пароли защищены
✅ формы сохраняют данные

### Деплой
✅ backend опубликован
✅ БД доступна онлайн
✅ секреты находятся в .env
