# Backend Plugins Required for AI Development

## Цель

Этот файл описывает плагины и инструменты, которые нужно подключить ChatGPT для максимально полной работы над backend частью проекта УП.08.

# Обязательные плагины

## GitHub Plugin ⭐

Главный плагин для работы с репозиторием.

Позволяет:
- читать файлы проекта;
- анализировать структуру backend;
- создавать и изменять файлы;
- делать коммиты;
- работать с Issues и Pull Request.

Используется на всех этапах.

---

## Code Analysis / Code Review

Используется для:
- анализа архитектуры;
- поиска ошибок;
- рефакторинга;
- проверки качества кода;
- проверки соответствия требованиям.

---

## Database Tools

Нужны для работы с БД.

Использование:
- проектирование структуры БД;
- проверка связей таблиц;
- создание миграций;
- анализ запросов.

Требование проекта:
- минимум 3 связанные таблицы.

---

## API Testing

Инструменты:
- Postman;
- Thunder Client.

Нужно для проверки:
- GET;
- POST;
- PUT/PATCH;
- DELETE;
- ошибок API.

---

## Документация

Нужно для создания:
- README;
- описания API;
- инструкции запуска;
- описания архитектуры.

# Рекомендуемый набор для полной работы

Минимум:
- GitHub Plugin;
- Code Review.

Оптимально:
- GitHub Plugin;
- Database инструменты;
- API Testing;
- Figma (если backend связан с UI);

# Backend считается готовым когда

✅ создан backend
✅ подключена база данных
✅ реализован API
✅ работают CRUD операции
✅ есть обработка ошибок
✅ есть документация запуска
✅ проект опубликован
