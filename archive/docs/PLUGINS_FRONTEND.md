# Frontend Plugins Required for AI Development

## Цель

Плагины, которые нужны ChatGPT для выполнения большей части frontend работы по УП.08.

# Обязательные плагины

## GitHub Plugin ⭐

Используется для:
- чтения проекта;
- создания компонентов;
- изменения файлов;
- проверки структуры;
- коммитов.

---

## Figma Plugin ⭐

Нужен для работы с дизайном.

Позволяет:
- анализировать макеты;
- переносить дизайн в код;
- проверять компоненты;
- работать с UI системой.

Используется на этапе дизайна и frontend разработки.

---

## Code Analysis

Используется для:
- проверки компонентов;
- поиска ошибок JavaScript/TypeScript;
- улучшения структуры проекта;
- проверки качества.

---

## UI/Design Tools

Используются для:
- создания UI-kit;
- проверки адаптивности;
- подготовки компонентов.

# Оптимальный набор

Для выполнения большинства задач:

1. GitHub Plugin
2. Figma Plugin
3. Code Review инструменты

# Frontend считается готовым когда

✅ создан проект через frontend-фреймворк
✅ есть компоненты
✅ есть адаптивная верстка
✅ работает навигация
✅ подключено API
✅ есть обработка ошибок
✅ выполнен деплой
